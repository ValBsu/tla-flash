# Polices locales

Fichiers WOFF2 officiels téléchargés le 25 octobre 2026 à partir de la feuille Google Fonts :

https://fonts.googleapis.com/css2?family=DM+Sans:wght@400..700&family=Space+Grotesk:wght@500..700&display=swap

- DM Sans v17 : variable, graisses 400 à 700, sous-ensembles latin et latin étendu.
- Space Grotesk v22 : variable, graisses 500 à 700, sous-ensembles latin et latin étendu.

Les familles, graisses, propriétés `font-display` et plages Unicode correspondent à la feuille officielle. Les URL relatives dans `src/index.css` permettent à Vite de copier, nommer et référencer ces fichiers selon le chemin de déploiement.

Licences SIL Open Font License, version 1.1, conservées dans chaque dossier :

- https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/spacegrotesk/OFL.txt

Une copie est aussi incluse dans `public/licenses/fonts/` afin que les licences accompagnent les polices dans le site de production.
